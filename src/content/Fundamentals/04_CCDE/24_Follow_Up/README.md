# 24. Follow-up

What to study next after this CCDE library, open questions, and how to keep notes alive.

## Study next (recommended order)

1. **Sit with the current Core Technology List PDF** and tick gaps (wireless, identity, SR details).
2. **Pick one Practical elective** and study only that extra list in depth.
3. **Protocol holes:** OSPF/IS-IS if weaker than BGP/EIGRP; multicast RPF; QoS trust.
4. **Scenario reps:** write one original R/C/A table per week from a real project.
5. **Assurance:** what telemetry would prove your last design.
