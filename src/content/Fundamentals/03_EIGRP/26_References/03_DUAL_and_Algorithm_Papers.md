# DUAL and Algorithm Papers

## Core idea sources

- Diffusing Update Algorithm (DUAL) — Garcia-Luna-Aceves and related work on loop-free routing via diffusion computations and feasibility conditions.
- RFC 7868’s DUAL exposition is the practical reading path for interviews; academic papers deepen *why* RD < FD is safe.

## What to extract for interviews

- Local computation vs diffusing computation  
- Feasibility Condition intuition (neighbor closer than our FD ⇒ cannot depend on us)  
- Active query scope as the cost of missing FS
