# BGP learning objectives

You should be able to:

- explain BGP as a policy-driven path-vector protocol;
- decode OPEN, UPDATE, KEEPALIVE, and NOTIFICATION messages;
- narrate the FSM from Idle to Established;
- distinguish Adj-RIB-In, Loc-RIB, Adj-RIB-Out, RIB, and FIB;
- interpret all core path attributes and attribute flags;
- predict route eligibility, best path, installation, and advertisement;
- design safe customer, provider, peer, and internal policies;
- explain iBGP split horizon, route reflection, path hiding, and ADD-PATH;
- use MP-BGP for IPv6, labeled unicast, VPN, EVPN, and other AFI/SAFIs;
- reason about BFD, graceful restart, PIC, and graceful shutdown;
- apply prefix, AS-path, community, RPKI, and route-leak controls;
- design resilient, low-latency BGP connectivity for trading systems;
- troubleshoot missing routes, inactive routes, asymmetry, churn, and leaks.
