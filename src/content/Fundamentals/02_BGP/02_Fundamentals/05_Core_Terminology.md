# Core BGP terminology

- **AS:** routing domain presenting a coherent external policy.
- **ASN:** Autonomous System Number; modern BGP supports four octets.
- **BGP speaker/peer:** router running BGP / neighbor with which it exchanges routes.
- **NLRI:** Network Layer Reachability Information.
- **eBGP/iBGP:** peering between different ASes / inside one AS.
- **BGP Identifier:** 32-bit value identifying a speaker; written like IPv4 but need not be a forwarding address under updated rules.
- **Best path:** locally selected BGP path for an NLRI.
- **Active path:** platform term usually meaning selected/installed; verify vendor usage.
- **RIB/FIB:** control-plane routing information / forwarding entries programmed for packets.
- **AFI/SAFI:** Address Family Identifier and Subsequent AFI defining the kind of NLRI.
