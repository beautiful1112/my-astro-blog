# Study, Discussion, and Update Workflow

For each topic:

1. Read the focused note.
2. Explain the mechanism from memory.
3. Draw or simulate one path change.
4. Answer the interview checkpoint.
5. Run the related lab.
6. Record anything unclear.

When discussing a question, identify the file and the exact statement. We can expand that document with packet fields, platform examples, diagrams, failure cases, or interview follow-ups without making unrelated notes larger.

Recommended first discussion path:

**TCP/FSM → RIB stages → attributes → best path → policy → iBGP/RR → convergence → security → trading cases**
