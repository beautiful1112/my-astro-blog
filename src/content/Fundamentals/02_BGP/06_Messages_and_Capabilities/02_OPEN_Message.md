# OPEN message

OPEN establishes session identity and negotiated behavior. Key fields are version 4, two-octet My Autonomous System field, Hold Time, BGP Identifier, and optional parameters.

Four-octet speakers advertise the 4-byte ASN capability. When needed for an old peer, the two-octet field carries AS_TRANS. Capability mismatches commonly explain an Established base session with an inactive address family or missing feature.
